# K-Means from Scratch

K-Means clustering written with only NumPy, including k-means++ initialisation, and checked against scikit-learn.

## What you'll learn

- How K-Means works step by step
- k-means++ initialisation
- Vectorised distance calculations with NumPy

## How to run

```bash
git clone https://github.com/Ddharsh1707/kmeans-from-scratch.git
cd kmeans-from-scratch
pip install -r requirements.txt
python main.py
```

No dataset download needed: the data is built into scikit-learn or generated by the script.
